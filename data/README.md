# Data

| folder | content | status |
|---|---|---|
| `raw/<session>/` | Board-generated IMU trials from `tools/hw/capture.py` (CSV + JSON metadata + session serial log) | **pending:** no real data has been collected yet |
| `synthetic/` | SYNTHETIC trials from `tools/ml/sigml/synth.py`, used only to test the pipeline (git-ignored, regenerated by `tools/ml/make_placeholder.py`) | not evidence |
| `splits.json` | session-to-split assignment for real data (train S01–S03, test S04, final trials F01) | template, confirm after collection |
| `splits_synthetic.json` | split for the synthetic placeholder | not evidence |

Collection protocol, labels, sampling rate, window length and exclusion rules: [docs/data_protocol.md](../docs/data_protocol.md).

## Trial file format

`<LABEL>_<nn>.csv` holds `seq,t_us,ax,ay,az,gx,gy,gz,flags`: raw two's-complement counts from the ICM-20608-G (±8 g → 4096 LSB/g, ±1000 dps → 32.8 LSB/dps), with `t_us` from the board's 1 MHz TIM2 counter. Flags are: bit0 invalid read, bit1 samples missed before this one, and bit2 DRDY interrupt absent (polled).

`<LABEL>_<nn>.json` holds the label, session, trial, the gyro bias reported by the board, the firmware/model ids, the quality summary, anonymous operator id, placement, surface, notes, and `excluded` / `exclusion_reason`. Rejected trials stay on disk with `excluded: true` as an audit trail; the trainer skips them.

## Manifest

Every training run writes `models/<model_id>/data_manifest.csv`. It lists one row per trial with its split, sample count, duration, window count and the file's SHA-256, so the exact training data can be reproduced and audited.

## Privacy

The data are motion counts of a box. Operators are recorded only as anonymous IDs (`P1`, `P2`). No names, faces, audio or locations are collected.
